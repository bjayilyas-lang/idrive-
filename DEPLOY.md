# Déploiement rapide

## Vercel
1. Importer le dossier dans le projet GitHub.
2. Framework Preset : **Other**.
3. Build Command : vide.
4. Output Directory : `.`.
5. Deploy.

## GitHub Pages
1. Push tous les fichiers à la racine du repository.
2. Settings → Pages.
3. Source : Deploy from branch.
4. Branch : `main` / `/root`.

`index.html` est autonome : il ne dépend pas d'un `app.js` ou d'un `style.css` externe pour le rendu principal.
