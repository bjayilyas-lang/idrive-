# DRIVE/RENT — Premium Car Rental Demo

Projet statique sans build : ouvre `index.html` dans un navigateur.

## Comptes démo
- Client : `client / client`
- Admin : `admin / admin`

## Pages
- index.html
- catalogue.html
- vehicle.html?id=12
- booking.html?id=12
- client.html
- compare.html
- admin.html
- admin-fleet.html
- admin-reservations.html
- admin-live.html
- admin-analytics.html
- login.html

## Fonctionnalités
- catalogue + filtres + recherche
- fiches véhicules
- configurateur couleur
- réservation + calcul de durée/options
- paiement simulé
- espace client
- comparateur
- favoris localStorage
- dashboard admin
- gestion flotte
- modification des prix depuis l'admin, sauvegardée en localStorage
- changement de statut
- ajout d'un véhicule de démonstration
- planning de réservations
- live location simulée
- analytics

## Prix
Les tarifs de base sont des tarifs de démonstration calibrés à partir de grilles publiques de location en France, notamment Audi Rent, Porsche Drive, Europcar et les catégories premium de SIXT. Les prix réels dépendent des dates, agences, kilométrage, assurance et disponibilité.
