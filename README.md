# DRIVE/RENT — version 3

Refonte complète de l'interface en s'appuyant sur les références fournies : interfaces automobiles claires, beaucoup d'espace, cartes bento, configurateur, tableau de bord et pilotage de flotte.

## Démo
- client / client
- admin / admin

## Fonctionnalités
- catalogue de modèles courants en location en France
- recherche et filtres avancés
- fiche véhicule inspirée d'un configurateur
- réservation en 3 étapes avec calendrier, options, assurances et paiement simulé
- espace client
- comparateur
- assistant IA de démonstration
- admin flotte avec édition des prix
- planning de réservations par jour
- carte stylisée de France avec positions live simulées
- analytics avec indicateurs animés et données qui se rafraîchissent
- responsive mobile

Les prix sont indicatifs pour une maquette et peuvent être modifiés depuis l'administration.
