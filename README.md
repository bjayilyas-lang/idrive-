# DRIVE/RENT — plateforme de location automobile

Version statique complète, pensée pour GitHub Pages / Vercel / Netlify.

## Démarrage

Ouvrir `index.html` ou déployer le dossier tel quel.

## Comptes démo

- Client : `client / client`
- Admin : `admin / admin`

## Fonctionnalités

- Home premium / Bento UI
- Catalogue, recherche, filtres
- 42 véhicules mock avec prix indicatifs
- Fiche véhicule + configurateur
- Réservation + calcul dynamique
- Assurance / options
- Paiement simulé
- Espace client
- Favoris
- Comparateur
- Assistant IA simulé
- Admin : flotte, prix, statuts, ajout véhicule
- Admin : réservations, live location, analytics
- Persistance des modifications dans localStorage

## Tarifs

Les prix de démonstration sont calibrés sur des grilles publiques de location premium. Ils doivent être considérés comme indicatifs et peuvent être modifiés depuis l'administration.

## Visuels

Les photos automobiles utilisent des URL publiques de démonstration. Pour une mise en production, remplacer les visuels par une bibliothèque d'images disposant des droits appropriés.
