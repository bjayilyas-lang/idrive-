# DRIVE/RENT V4

Refonte interactive inspirée des deux références fournies : interface claire de cockpit automobile + configurateur premium.

Fonctions : accueil animé, assistant IA, flotte de 38 modèles, filtres, fiches véhicules, configurateur, réservation en 3 étapes, comparateur, espace client, dashboard admin, planning interactif, édition des réservations et contact client, carte de France Leaflet/OpenStreetMap, analytics animés, favoris et recherche de commandes.

Identifiants démo : client/client et admin/admin.

Les visuels sont renseignés uniquement lorsqu'un visuel correspond au modèle ; sinon l'interface affiche explicitement qu'aucun visuel exact n'est disponible. Les URLs de visuels externes doivent être remplacées par des assets dont vous détenez les droits avant production.
